# PromptMe 🗣️

**PromptMe** is a minimalist, browser-based teleprompter that works entirely offline. It lets you paste and scroll your script effortlessly using keyboard shortcuts.

### 🚀 Features
- 🖋️ Live editable script area
- ⌨️ Scroll with Page Up/Down or Arrow Up/Down
- 🔠 Adjustable font size
- 💡 Info/help button
- 📴 Fully offline & privacy-friendly
- 🌐 Easy to host via GitHub Pages

### 🧑‍💻 How to Use
1. Paste your script into the main window.
2. Use `Page Up/Down` or `Arrow Up/Down` to scroll.
3. Adjust text size with `A-` / `A+` buttons.

### 📦 Deployment
1. Clone this repo or upload `index.html` to a new GitHub repo.
2. Go to **Settings > Pages** and select the root directory of the `main` branch.
3. Done! Your teleprompter is live at `https://yourusername.github.io/repo-name`.
